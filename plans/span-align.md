# TODO по выравниванию текста в объединённых ячейках шапки

Что уже сделано: выравнивание текста (`SpanAlignment { horizontal, vertical }`) в объединённых
ячейках шапки — на колонке (`spanGroupHeaderAlign`), на группе (`getGroupDetails().spanAlign`)
и по умолчанию на гриде (`spanAlign`). Ниже — то, что осознанно отложили.

## RTL
Сейчас выравнивание работает только для LTR. Для RTL-заголовков рисуем как раньше (без
выравнивания). Нужно: посчитать бокс с учётом направления (иконка справа, отступы зеркалятся)
и поддержать `left/right` относительно направления письма.

## Один источник для значения по умолчанию
Значение по умолчанию (`spanAlign` с грида) сейчас подставляется в двух местах: для колонок —
в `useMappedColumns`, для групп — в `mangledGetGroupDetails`. Работает, но лучше свести к одному
месту (например, резолвить всё в рендере), чтобы не держать две одинаковые точки.

## Убрать магические числа в группе
В `drawGroupHeaderInner` иконка сдвигает текст на хардкод `26`, а отступ — `xPad = 8`, тогда как
рядом уже используется `theme.cellHorizontalPadding`. Свести к отступам из темы.

## Больше вариантов выравнивания
Если понадобится — добавить `stretch`/`justify` и т.п. Тип `SpanAlignment` — объект, так что
расширяется без ломки существующего API.

## Переиспользование для ячеек тела
Тот же `SpanAlignment` и хелпер `drawSpanAlignedText` планируем использовать при объединении
обычных ячеек таблицы. Горизонталь можно брать из `cell.contentAlign`, вертикаль — новая.
