## Планы / отложено (по этой фиче)

### Выравнивание
- **RTL:** сейчас LTR-only; для RTL-заголовков рисуем без выравнивания. Нужно считать бокс с учётом
  направления (иконка справа, зеркальные отступы) и `left/right` относительно письма.
- **Один источник дефолта:** `spanAlign` с грида подставляется в ДВУХ местах (`useMappedColumns` для
  колонок, `mangledGetGroupDetails` для групп) — свести к одному (резолвить в рендере).
- **Больше вариантов:** при надобности `stretch`/`justify` — тип `SpanAlignment` объектный, расширяется
  без ломки API.

### Переиспользование для ячеек ТЕЛА
`SpanAlignment` + `drawSpanAlignedText` + региональные хелперы переиспользуем при **объединении обычных
ячеек таблицы** (rowspan/прямоугольник + 2D-выравнивание). В работе — ветка `feat/span-cells`.

## Известные нативные баги glide (НЕ наши — кандидаты в отдельный PR)

Найдены при работе над фичей, но воспроизводятся на **обычных** группах, которых фича не касается →
предсуществующее поведение форка/glide. Проверка «наше/нативное» — `git stash` наших правок: эффекты
остаются. Держим здесь до решения с Рамилём.

### 1. Hover-мигание на границе подколонок внутри группы
Ведёшь мышью внутри одной групп-ячейки, пересекаешь границу подколонок — заливка на долю секунды
мигает. Причина: hover групп-шапки трекается **по колонке** (`hCol`), а не по группе/спану — при
смене `hCol` анимация старой колонки гаснет, новой разгоняется с нуля. Фикс: считать hover по
идентичности группы/спана (max по колонкам спана). Приоритет низкий (косметика).

### 2. Шрифт групп-шапки (ambient font + FOUT)
На первом рендере текст групп-шапки нарисован «не тем» шрифтом; после перерисовки (hover) — правильным.
Причины: (1) `drawGroupHeaderInner` не ставит `ctx.font` перед `fillText` (рисует окружающим шрифтом);
(2) FOUT — первая отрисовка до загрузки веб-шрифта. Фикс: явно ставить `ctx.font = theme.headerFontFull`
+ перерисовка по `document.fonts.ready`. Приоритет низкий-средний (заметно на первом рендере).

### 3. Групп-выделение: focus-рамка вылезает на 1px сверху («усик»)
Кликаешь по групп-шапке (выделяется группа) — тонкая accent-линия по верхней кромке групп-ячейки
выступает на ~1px за правый бордер (пропадает после скролла). **Первопричину нашли, фикс проверен —
но по решению с Рамилём пока НЕ трогаем.**

Механизм: focus-обводка текущей ячейки (`highlightFocus = gridSelection.current.cell`; для группы
`cell = [start, -2]`) рисуется в `drawHighlightRings` (`render/data-grid.render.rings.ts`) по геометрии
из `computeBounds`, а та возвращает ширину с **+1** (`data-grid-lib.ts`, правый бордер — для bounds
оверлей-редактора). `drawHighlightRings` компенсирует `+1` только у края грида → для группы в середине
обводка на 1px шире заливки. `+1` есть у всех header-обводок, но заметнее всего на групп-шапке.

Фикс (проверен, откатили):
- (a) не рисовать focus-рамку для групп-рядов (`highlightFocusRow <= -2`) в `data-editor.tsx` —
  группе рамка избыточна (её показывает заливка). Минус: рамка у групп пропадает вовсе.
- (a2) оставить рамку, но вычесть лишний 1px у header-обводок в `drawHighlightRings` (для регионов
  `range.y < 0`) — рамка сохраняется; аккуратнее по коду (учесть край грида).

Приоритет низкий (косметика, 1px). Меняет общий рендер выделения групп glide → отдельный PR.
