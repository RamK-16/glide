# Нативные баги glide в групп-шапке (НЕ наши, кандидаты на отдельный PR)

Найдены при работе над `spanShallowGroups` (rowspan групп). **Воспроизводятся на обычных
группах, которых наша фича не касается** (напр. двухуровневая `2024 → Q1`), и в коде шрифта/hover
мы ничего не меняли → это предсуществующее поведение форка/glide. Вынесены сюда, чтобы вернуться
отдельным мелким PR, если дизайн потребует. Проверка «наше/нативное» — `git stash` наших правок:
эффекты остаются.

---

## 1. Мигание hover при переходе границы подколонок внутри группы

**Симптом:** ведёшь мышью по X внутри одной групп-ячейки (напр. `Q1`), пересекаешь границу
подколонок `Q1-A | Q1-B` (по Y всё ещё в `Q1`) — заливка групп-ячейки на долю секунды мигает
(гаснет/разгорается).

**Механизм:** hover групп-шапки трекается **по колонке**, а не по группе.
`internal/data-grid/render/data-grid-render.header.ts`, `drawGroupLevel`:
```
hoverAmount = ... _hoverValues.find(s => s.item[0] === hCol && s.item[1] === targetRow)?.hoverAmount
```
— «сила» hover привязана к конкретной наведённой колонке `hCol`. При переходе `Q1-A → Q1-B`
`hCol` меняется → анимация старой колонки гаснет, новой разгоняется с нуля → на стыке просадка
`hoverAmount` + смена hovered-item damage'ит и перерисовывает ячейку.

**Предлагаемый фикс:** для групп-ряда считать hover по **идентичности группы/спана**, а не по
`hCol` (например, брать max hoverAmount по колонкам спана, либо трекать hover-ключ группы).
Меняет нативное поведение для ВСЕХ групп → отдельный PR, согласовать с Рамилем.

**Приоритет:** низкий (косметика). Наша слитая ячейка ведёт себя так же (при переходе
Индивид→Коллект внутри KPI) — тем же нативным образом.

## 2. Шрифт текста групп-шапки: ambient font + FOUT

**Симптом:** при открытии Storybook текст групп-шапки («2024», «Q1», «Коэффициент
результативности») отрисован «не тем» шрифтом (уже/иначе); после наведения (перерисовки)
становится шире/правильным.

**Механизм (две причины):**
1. `drawGroupHeaderInner` (`data-grid-render.header.ts`, ~стр. 383-396) **не выставляет
   `ctx.font`** перед `fillText` — рисует «окружающим» шрифтом канваса; `theme.headerFontFull`
   идёт только в `getMiddleCenterBias` (вертикальный сдвиг), не в сам шрифт.
2. FOUT: первая отрисовка — до загрузки веб-шрифта темы → системный фолбэк (узкий); шрифт
   догружается → следующая перерисовка (её триггерит hover/`document.fonts.ready`) рисует
   правильным (широким). «Широкий» после hover — это КОРРЕКТНОЕ состояние.

**Предлагаемый фикс:** в `drawGroupHeaderInner` явно ставить `ctx.font = theme.headerFontFull`
(или `groupTheme.*`) перед `fillText`; гарантировать перерисовку шапки по `document.fonts.ready`.

**Приоритет:** низкий-средний (заметно на первом рендере). Правит все групп-шапки glide, вне нашей
фичи → отдельный PR.
